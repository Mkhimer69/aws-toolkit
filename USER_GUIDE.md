# 🚀 AWS Toolkit User Guide

AWS Toolkit helps automate common Amazon Connect user administration tasks.

---

# Getting Started

## Opening AWS Toolkit

1. Open Amazon Connect Users page.
2. Wait for the page to load.
3. AWS Toolkit appears in the top-right corner.

Example:

🚀 AWS Toolkit v2.2

---

# Feature 1: Add Users

Use this feature to build a list of users for bulk actions.

## Steps

1. Copy an email address to your clipboard.

Example:

john.doe@example.com

2. Click:

📥 Add

3. A confirmation message appears:

Saved

4. Repeat for additional users.

## Notes

- Duplicate emails are ignored.
- Emails are stored locally in your browser.

---

# Feature 2: Show Stored Users

View the current user list.

## Steps

Click:

📋 Show

The stored emails will appear underneath the buttons.

---

# Feature 3: Select Users

Bulk-select users from the stored email list.

## Steps

1. Add users using 📥 Add.
2. Click:

✅ Select

3. AWS Toolkit will:

- Search each email
- Find the matching user
- Select the checkbox automatically

## Status Updates

Examples:

Selecting 1/10

Selecting 2/10

Selecting 3/10

✅ Selection Complete

---

# Feature 4: Deselect Users

Bulk-deselect users from the stored email list.

## Steps

1. Add users using 📥 Add.
2. Click:

❌ Deselect

AWS Toolkit will automatically remove the checkmarks.

---

# Feature 5: Routing Profile Management

Apply routing profiles automatically to selected users.

## Supported Profiles

### Driver

- Driver Chat Focus
- Driver Default Omnichannel
- Driver Email Focus
- Driver Voice Focus

### Rider

- Rider Chat Single Concurrency
- Rider Email
- Rider Omnichannel

### Safety

- Safety Chat - Training
- Safety Email - Training
- Safety General
- Safety SMAA AST Sutherland
- Safety SMAA Sutherland

### Supervisor

- Supervisor - Sutherland

---

## Applying A Routing Profile

### Step 1

Select one or more users.

### Step 2

Choose a routing profile from the dropdown.

Example:

Safety General

### Step 3

Click:

🚀 Apply Profile

### Step 4

Wait for completion.

Example:

Applying Safety General...

✅ Safety General Applied

---

# Feature 6: Clear Stored Users

Removes all stored emails.

## Steps

Click:

🧹 Clear

Confirmation:

Cleared

Click and hold the blue header.

Drag the toolkit to any location on the screen.

---

# Troubleshooting

## "No emails"

Cause:

No users have been added.

Solution:

Use 📥 Add first.

---

## "Search box not found"

Cause:

Amazon Connect page did not load correctly.

Solution:

Refresh the page and try again.

---

## "Profile not found"

Cause:

Selected routing profile may not exist or the page is still loading.

Solution:

1. Wait a few seconds.
2. Try again.
3. Refresh the page if necessary.

---

# Best Practice Workflow

1. Copy user email.
2. Click 📥 Add.
3. Repeat until all users are added.
4. Click ✅ Select.
5. Choose routing profile.
6. Click 🚀 Apply Profile.
7. Verify the update.
8. Click 🧹 Clear when finished.
