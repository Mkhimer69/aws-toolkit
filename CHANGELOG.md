## v3.0

### Added
- **Cross-Origin Analytics Bridge:** Integrated an automatic data relay layer utilizing `localStorage` and focus event bindings to bridge the telemetry gap between `/analytics-dashboards` and `/users*`.
- **Dynamic Routing Profile Counters:** Real-time extraction logic calculating exact active agent footprints per queue. Footprints are dynamically rendered as contextual counters directly within the configuration dropdown.
- **Fisher-Yates Shuffling Injection:** Random agent deployment engine allowing administrative batches to be selected and moved smoothly without cherry-picking metrics.
- **Advanced RegExp Filter:** High-efficiency regular expression engine parsing raw, unformatted clipboard text strings to identify, isolate, and extract valid email shapes.

### Improved
- **Concurrent Task Resolution:** Scraper engine upgraded from sequential loops to asynchronous `Promise.all` intercepts, cutting down pipeline latency across heavily loaded dashboard frames.
- **Robust Exception Sandboxing:** Added comprehensive error boundary wrappers around `window.fetch` streams to protect the core Amazon Connect application telemetry if network packets arrive incomplete.
- **UI Responsiveness:** Draggable floating anchors modified with a precise boundary matrix, resolving historical jitter and keeping long operations from freezing tab threads.
